
![GROOVE JIGOKU VI](header.svg)

『グルーヴ地獄V』のシーケンス再生機能をWeb Audioで再現する実験的なブラウザアプリです。

## 使ってみる

こちらからアクセスできます: https://106-.github.io/groove-jigoku-vi/

## できること

### DJ プレイ

B×40 / H×40 / S×160 の音ネタ(バイト不要)から6本を選んでループ再生。
L1・L2にベースかハイハット、R1・R2にシーケンスを2本ずつ入れる構成。

- **セット切替** — ア～クの8セットを演奏を止めずに切り替え。ホイール押し込みで一時切替、離すと元のセットに戻る
- **SEQ ON/OFF** — 6本の音ネタを個別にミュート/復帰。Sペアはまとめてもできる
- **HOLD SOLO** — 音ネタカードをホイール押し込みで、押している間だけソロ試聴
- **音ネタ選択** — フィルター・検索・1小節の試聴ができる選択画面。ホイール上下で前後の音ネタに切り替え
- **TECH(音響効果)** — 原作10種すべて対応。ボタンを押している間だけ効果がかかる
- **TECHホットキー** — キーボードの3行(YUIO/HJKL/NM,.)にTECHを割り当てて、キーホールドで発動

### タイムライン

演奏をタイムライン上に配置・編集できるエディター。

- **プリセット** — ディスク収録の FMY / PIG / SEX(サンプルプレイの内部名) をプリセットとして読み込み、再生・編集できる
- **MCD読込** — PS1メモリーカードファイル (.mcd) から直接リプレイデータを選択・読み込み。単体の .DENR ファイルにも対応(ちょっとずれるかも)
- **REC** — ライブ演奏をそのままタイムラインとして記録
- **編集** — チャンク切替・レーンON/OFF・TECH・頭出しをドラッグ/リサイズ/追加/削除。スナップ・ズーム付き
- **JSON書き出し/読み込み** — 作ったタイムラインをファイルとして保存・共有

### その他

- **ボールペンコウジョウ** - コンベアで流れてくるボールペンにキャップをはめる労働

## TECH名と動作

正式名称は原作説明書の記載に基づく。

| 表示 | 正式名称 | ホールド中の動作 |
| --- | --- | --- |
| DLY | Delay | 鳴った音を拍に合わせて遅らせ、カノンのように反復する |
| MOD | Modulation | 全パートの音程を三角波LFOで周期的に揺らす |
| REV | Reverb | トンネル内のような長い残響を原音に重ねる |
| BPM | BPM | 再生速度と音程をテープのように徐々に上げ下げする |
| STB | Stab | 方向キーを押すたびに効果音を加える |
| ARP | Arpeggiator | TB-303風の音程付きシーケンスを重ね、解除後は徐々に減衰する |
| FLSH | Flash | 専用の短い音を、選んだ拍間隔で再発音する |
| INT | Interval Mute | シーケンサを一定間隔で切り、ゲートのように刻む |
| FIL | Fill | 演奏中のチャンクを様々なリズムでアタマ出しし、フィルを作る |
| MRG | Mirage | 専用のループするアシッド音を、押した瞬間から重ねる |
