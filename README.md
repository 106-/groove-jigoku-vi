# GROOVE JIGOKU VI

![](https://i.imgur.com/vyko16f.png)

『グルーヴ地獄V』のシーケンス再生機能をWeb Audioで再現する実験的なブラウザアプリです。

## 使ってみる

こちらからアクセスできます: https://106-.github.io/groove-jigoku-vi/

## 現在の機能

- B01–B40、H01–H40、S001–S160
- 240音ネタ、953 SPTN小節
- ディスク収録のFMY／PIG／SEXリプレイを、調整済みタイムライン（gj6-timeline）のプリセットとしてエディターから読み込み・試聴（プレイヘッド追従、そのまま編集可能）
- DENRパッド記録→タイムラインの変換器も保持: エディターの「読み込み」に .DENR セーブファイルを渡すと変換して展開、「DENR原本」で調整前のプリセット原本も展開可能
- リプレイ中のL1/L2/R1/R2、CHANGEチャンク切替（24tick窓量子化）、方向TECHホールド、○頭出しを反映
- タイムラインエディター: チャンク切替・レーンON/OFF区間・TECH区間・頭出しをドラッグ/リサイズ/追加/削除、スナップ（6〜192tick）、ズーム、カーソル位置からの試聴、JSON書き出し/読み込み、localStorage草稿自動保存
- ライブ演奏の収録: REC待機→PLAYで、セット切替・SEQ切替・TECHホールド・頭出しをタイムラインとして記録しエディターへ展開
- 各音ネタに含まれる3～4小節を順番に演奏してループ
- 選択中の6音ネタを16ステップで可視化（正確なtick位置、音量、音価、プレイヘッド）
- L1/L2にBまたはHを各1本
- R1/R2にSを各2本（合計6音ネタ）
- 6音ネタの個別SEQ ON/OFF（Sペアはペア全体のALL ON/OFFも可能）
- Q/W/E/RキーでL1/L2/R1/R2のSEQ/ALL ON/OFFを切り替え
- 音色フィルター・検索・発音を含む1小節の試聴を備えた音ネタ選択モーダル
- 再生中の試聴を次小節頭へ同期して通常ミックスへ重ね合わせ
- 音ネタをホイールクリックしている間だけ共通クロック上で単体SOLO再生
- メイン画面のBASS / HI-HAT TYPE欄とカード見出しでもHOLD SOLO
- L1/L2カード全体は単体SOLO、R1/R2カード全体はS-A＋S-BのペアSOLO
- R1/R2の各音ネタ選択ボックス上では、そのSEQだけを単体SOLO
- HOLD SOLO中は対象カードの振幅メーターだけを表示
- HOLD SOLO中は16ビート表示も対象SEQだけをアクティブ表示
- 音ネタボタン上でホイール上下による前後切り替え（先頭・末尾は循環）
- 共通クロックを維持した8セット切り替え
- ア～クのセットボタンをホイール押し込み中だけ一時切り替え（解除時に元のセットへ復帰）
- 頭出し、BPM、マスターボリューム
- 原作の4段階に基づくDLY（12・24・32・48 tickのカノン型反復）とREV（深さ16・32・64・127、5.2秒のトンネル型残響）
- 原作のQ7速度処理に基づくBPM TECH（毎フレーム−3・−9・＋3・＋9、×0.125～×4、再生音程もテープ風に追従し、解除時は等速へ復帰）
- 原作のデータと処理に基づくINT（4ボタンからシーケンサ・ミュートを直接ホールド）とFIL（4×4の16ボタンから直接ホールド実行）
- 原作の専用シーケンサとVAB Program 92–95を使うARP（4フレーズ×4音色、拍同期の開始とシーケンスを続けながら減衰するリリース）
- VAB Program 64–67を48・24・12・8 tick間隔で再発音するFLSH（4音色×4速度、ホールド実行）
- 原作VABのProgram 76–79と専用ループ波形を使うMRG（4音色×4音程、押下時に即時キーオン）
- INTホールド中は、16ビート表示で発音するノーツは従来色、INTでカットされるノーツは別色で表示
- 8セットの設定をブラウザのlocalStorageへ保存
- 確認付きの8セット初期設定リセット
- 現在セットのランダム選択（B/H×2、重複なしS×4）

## TECH名と動作

| 表示 | 元の単語 | ホールド中の動作 |
| --- | --- | --- |
| DLY | Delay | 鳴った音を拍に合わせて遅らせ、カノンのように反復する |
| BPM | Beats Per Minute | 再生速度と音程をテープのように徐々に上げ下げする |
| REV | Reverb | トンネル内のような長い残響を原音に重ねる |
| ARP | Arpeggio | TB-303風の音程付きシーケンスを重ね、解除後は徐々に減衰する |
| FLSH | Flash | 専用の短い音を、選んだ拍間隔で再発音する |
| MRG | Merge？（推定） | 専用のループするアシッド音を、押した瞬間から重ねる |
| INT | Interrupt | シーケンサを一定間隔で切り、ゲートのように刻む |
| FIL | Fill | 現在のシーケンスの頭出しをパターンに従って反復し、フィルを作る |

`MRG` は原作データ内でも `Mrg` とのみ表記され、展開語は収録文字列から確認できません。`Merge` は「原音へ専用音を重ねる」動作からの推定です。
